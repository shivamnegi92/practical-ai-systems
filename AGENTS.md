# Repository guidance for AI coding agents

- This repository is a **decision layer and curated field guide**, not a monolith or automatic mirror of other catalogs.
- `catalog/projects.json` is the canonical active catalog. `catalog/*.md` and the marked README browse index are generated by `scripts/build_catalog.py`.
- `.claude/skills/practical-ai-systems-trend-curator/SKILL.md` records discovery/review workflows and uses the project catalog as its source of truth.
- Read `CONTRIBUTING.md` before adding entries. Verify current canonical URLs, licenses, origin evidence, maintenance, and meaningful tradeoffs.
- Never include China-origin models/vendors/frameworks. Assess project/vendor origin with reliable public evidence, never a person's name or nationality; ambiguity means hold.
- Do not bulk-copy upstream catalog entries, code, or prose. Add original decision guides, caveats, evidence, reproducible methodology, and canonical links.
- Don't claim testing, trending status, production readiness, safety, or rankings unless the method/source supports it.
- Check `git status` before editing; preserve unrelated work. Do not publish, commit, push, or open a PR unless the user explicitly requests it.
- After catalog or example changes run `python3 scripts/build_catalog.py --write`, `python3 -m unittest discover -s tests -v`, `python3 -m unittest discover -s tests -p 'test_paths.py' -v`, `python3 -m unittest discover -s examples -p 'test_*.py' -v`, `python3 scripts/build_catalog.py`, and `git diff --check`.
