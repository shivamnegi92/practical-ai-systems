Local Knowledge-Base MCP-Style Server

Issue a JSON-RPC-shaped tools/call request against a local BM25 search tool. The real Python version speaks this protocol over stdio; this page calls the same dispatch logic directly in your browser.


  
  

  
Known limitations: this demo calls the dispatch function directly instead of over
  real stdio transport, and the corpus is tiny and synthetic. See the project README for the full write-up and the Python stdio server.
