# Release 0.1.0 checklist

Do not tag this release until every item is verified:

- [ ] Ten systems each run from a fresh clone with documented commands.
- [ ] `eval/results.json` exactly reproduces from the committed code and data.
- [ ] All unit tests, generated-view checks, Markdown links, and CI pass.
- [ ] Every README names the measured scope, sample size, failure cases, limitations, and when not to use it.
- [ ] No credential, network dependency, private data, copied material, or endorsement implication in default flows.
- [ ] License and attribution reviewed for any added code/data/dependencies.
- [ ] Changelog updated and public description/topics/social preview reviewed.
- [ ] At least one second maintainer has reviewed the release candidate.

If criteria are not met, keep the release as planned; do not manufacture a tag to satisfy a roadmap.
