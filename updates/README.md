# Catalog update records

Dated catalog refresh reports belong here. Each report should record its search window, sources, candidate evidence, decisions, uncertainty, and applied changes. A discovery report is not an endorsement and does not prove that a project is currently trending unless the source explicitly showed that status during the recorded window.

Run the project-local skill at `.claude/skills/practical-ai-systems-trend-curator/SKILL.md` to perform a refresh.
